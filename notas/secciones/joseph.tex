\subsection{Verificación externa propuesta mediante SOAP}

El PFC plantea un sistema para organizar historiales médicos y citas. En el alcance definido hasta ahora no consta una integración implementada con un proveedor externo; por eso, el flujo descrito aquí es una propuesta futura.

Como escenario, el sistema podría consultar a un proveedor hipotético si una cobertura médica está vigente. El PFC actuaría como cliente y enviaría una solicitud SOAP en XML con un identificador de cobertura de prueba y la fecha de consulta. No se usarían datos personales reales.

SOAP sería una opción si el proveedor ofreciera la operación mediante un contrato WSDL. Ese contrato permitiría conocer las operaciones disponibles, los mensajes y los tipos esperados. La respuesta indicaría si la cobertura está vigente para que el sistema muestre el resultado al usuario. Esta comunicación todavía no está implementada ni comprobada con un proveedor real.
